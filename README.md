# 草！躲避！

一个用JavaScript和Canvas编写的躲避小游戏。控制黑球移动，避开障碍和白球，收集积分与道具；积分可用于游戏内商城。不同模式有独立规则与记录。

## 为什么做这个项目

这是一次vibe coding学习实践。我想通过一个完整的小项目，练习描述需求、拆分问题，以及与Codex协作推进开发，观察它在功能实现、理解上下文、调试和持续修改方面的能力与局限。

同时，也用它练习测试与纠正：检查生成结果是否符合要求，记录能重现的问题，用测试验证规则和边界，再提出更准确的修改要求。项目不是手工独立编写全部代码的展示；大量代码由Codex辅助生成，我负责需求、玩法与交互取舍、试用反馈，以及对结果的检查和纠正。

## 玩法

电脑用鼠标引导黑球，手机可选手指跟随或浮动摇杆。支持暂停；积分、护盾等道具在不同模式下生成和作用有所不同。

| 模式 | 规则 |
| --- | --- |
| 经典模式 | 躲避移动障碍与白球，拾取积分和道具；接触安全拖尾可消除它们并积累草值 |
| 困难模式 | 障碍拖尾也有危险，护盾先储存，受伤时自动消耗救场 |
| 黑白世界 | 经典规则，使用黑白配色 |
| 竞速模式 | 30秒内收集实心大圆，清完一批进入下一轮；白球有伤害，记录消除个数 |
| 双生循环 | 黑白两球在圆轨道上对称移动；黑球躲避，白球可击破障碍，记录存活时间 |
| 无尽试炼 | 不生成普通障碍，白球逐渐增加；正常生成积分，记录存活时间 |

草值是表现记录，商城积分是另一种数值。另含本地成就、外观/音效商城，以及可选TapTap排行榜与激励广告接入代码。

## 本地运行

需要Node.js 22或更新版本。运行与构建不依赖第三方npm包：

```sh
node build.cjs
node serve.cjs
```

打开终端显示的地址（默认http://127.0.0.1:4328）。也可用`npm start`。构建后可直接打开`play.html`；`index.html`需保留src/和style.css。存档按浏览器来源保存，更换地址或浏览器不一定能读取原进度。
