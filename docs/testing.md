# 测试方法与历史记录

## 按需运行

逻辑测试用Node内置node:test与assert，不需安装依赖：`npm test`。

浏览器专项准备：

```sh
npm install
npx playwright install chromium
node build.cjs
npm run test:browser
npm run test:browser -- browser-revive.cjs
```

无参数只列出专项。默认Playwright Chromium，可设PIXEL_BROWSER_CHANNEL=msedge使用本机Edge；Windows PowerShell使用`$env:PIXEL_BROWSER_CHANNEL='msedge'`。PIXEL_REVIVE_COMPACT=1仅检查源码入口手机视口，默认双入口四视口。截图和JSON写qa/，测试上下文隔离，不访问日常存档。

## 用例示例

| 场景 | 前置/操作 | 预期 |
| --- | --- | --- |
| 提前关闭 | 未拥有商品，广告isEnded=false | 不授奖、不扣钱，可重试 |
| 旧回调 | 旧广告结束、新请求开始后触发旧成功 | 不串奖、不重复入账 |
| 复活上限 | 六模式第一次受伤完整观看，再次受伤 | 原局保留、立即护盾，第二次最终结算 |
| 等待冻结 | 拖尾存在时停留复活选择 | 时间、拖尾寿命不推进 |
| 成就阈值 | 困难同持9→10盾、生存59.99→60秒 | 达到触发、同局去重 |
| 多指接力 | A控制，B按住移动，松开A | 一个轮盘移交B最新位置并居中 |
| 横屏失败 | API拒绝或不返回 | 不阻塞竖屏游玩，清理迟到请求 |
| 开始按钮 | 双入口多尺寸切六模式 | 单行、无裁切、能开始和暂停退出 |
