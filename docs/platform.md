# 可选平台接入

src/platform-config.js为空示例，不含原广告位、榜单ID、账号凭据或服务端密钥。按自己的应用填写激励视频ID和六模式榜单ID。H5与Android配置分开保留，Android实际桥接需另行实现与验证。

模块依赖宿主tap接口。普通浏览器给友好提示，不模拟真实平台奖励。指定商城商品各看一次完整广告获取；受伤后每局可成功复活一次，立即带4秒护盾；竞速正常到时及主动退出不弹复活。前端逻辑不是服务端广告防作弊方案。

不要将OAuth令牌、Client Secret或服务端密钥放入前端。本项目没有真实广告播放、收入或审核通过承诺。接入后须在目标平台验证登录、完整/提前关闭、无填充、网络失败、音频恢复、榜单和存档。

可选打包：`python tools/package-h5.py --version 1.0.7`。输出唯一外层taptap-h5/，内部为index.html与字形许可；本地结构和CRC通过不代表平台审核通过。
